# 🧠 Estruturas de Controle em Java

Este projeto Java demonstra o uso básico das principais **estruturas de controle** da linguagem Java, ideal para iniciantes que desejam praticar lógica de programação e entrada de dados com `Scanner`.

## 📋 O que o programa faz?

O programa realiza as seguintes operações:

1. ✅ **Verifica a maioridade** com `if-else`
2. 📅 **Mostra o dia da semana** usando `switch`
3. ✖️ **Exibe a tabuada do 5** com `for`
4. 🔁 **Conta até 5** usando `while`
5. 📝 **Recebe e avalia notas** com `do-while`

Tudo isso com interação no terminal via entrada do usuário! 🧑‍💻

---

## 💡 Tecnologias Utilizadas

- ☕ Java (JDK 8+)
- 🖥️ IDEs recomendadas: VS Code, IntelliJ ou Eclipse
- 📦 `Scanner` para leitura de dados no console

---

## 🚀 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/estruturas-controle-java.git
   ```

2. Compile o arquivo:
   ```bash
   javac EstruturasControle.java
   ```

3. Execute o programa:
   ```bash
   java EstruturasControle
   ```
